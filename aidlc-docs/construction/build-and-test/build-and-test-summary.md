아래 결과는 고정 파일로 새 가상 환경을 만들어 실제로 실행한 값이다.

## 빌드 상태
- **빌드 도구**: pip + venv (컴파일 단계 없음)
- **빌드 상태**: 성공
- **확인 내용**: `requirements-dev.txt`로 새 가상 환경에 설치(패키지 45개), `pip check` 정상, `compileall` 정상
- **산출물**: 별도 패키지 없음. `src/todo_api/`를 직접 실행
- **소요 시간**: 의존성 설치 약 5초

## 확인하지 못한 항목

| 항목 | 이유 | 확인 방법 |
|---|---|---|
| GitHub Actions 워크플로 실행 | 로컬에서 실행할 수 없음 | GitHub에 푸시한 뒤 Actions 탭에서 첫 실행 결과 확인 |
| Windows에서의 실행 | WSL에서만 검증 | Windows Python 3.12에서 같은 절차 수행. 파일 권한 테스트 1개는 Windows에서 건너뜀 |
| 디스크 암호화 | 운영 환경 설정 | DB가 있는 볼륨의 암호화 여부를 직접 확인 |
| 실제 HTTP 구간을 포함한 응답 시간 | 따로 측정하지 않음 | 필요하면 실행 중인 서버에 `curl -w "%{time_total}"`로 측정 |
