# 기술 스택 결정 - todo-api

버전은 2026-10-12에 PyPI에서 확인한 최신 안정 버전이다. 정확한 고정 버전(하위 의존성 포함)은 Code Generation 단계에서 실제 설치 결과를 기준으로 `requirements.txt`에 기록한다.

## 1. 런타임

| 항목 | 결정 | 근거 |
|---|---|---|
| 언어 | Python 3.12 | NFR-Q1:A. WSL에 3.12.3 설치됨. 아래 모든 라이브러리의 지원 범위에 포함 |
| 가상 환경 | 표준 `venv` | 추가 도구 없음 |

**확인된 환경 제약**: 현재 WSL의 Python에는 `ensurepip`가 없어 `python3 -m venv`로 pip가 포함된 가상 환경을 바로 만들 수 없다. `python3.12-venv` 패키지 설치(`sudo apt install python3.12-venv`)가 필요하며, 이는 Code Generation 검증과 Build and Test 단계의 선행 조건이다.

## 2. 실행 의존성

| 라이브러리 | 버전 | 용도 | 근거 |
|---|---|---|---|
| Flask | 3.1.x (확인 버전 3.1.3) | 웹 프레임워크 | 사용자 요청 |
| Flask-Limiter | 4.1.x (확인 버전 4.1.1) | 요청 제한, 메모리 저장소 | NFR-Q4:A |
| Waitress | 3.0.x (확인 버전 3.0.2) | WSGI 서버 | NFR-Q6:B |
| sqlite3 | 표준 라이브러리 | DB 접근 | 추가 질문 1:A |
| logging | 표준 라이브러리 | JSON 구조화 로그 (자체 포매터) | 의존성 최소화 |

## 3. 개발 및 테스트 의존성

| 라이브러리 | 버전 | 용도 | 근거 |
|---|---|---|---|
| pytest | 9.1.x (확인 버전 9.1.1) | 테스트 러너 | Q8:A |
| Hypothesis | 6.x (확인 버전 6.169.0) | 속성 기반 테스트 | PBT-09 |
| pip-audit | 2.10.x (확인 버전 2.10.1) | 의존성 취약점 스캔 | SECURITY-10 |

### Hypothesis 선정 근거 (PBT-09)
- 도메인 전용 제너레이터(strategy) 정의 지원
- 실패 입력 자동 축소(shrinking)
- 시드 기반 재현 (실패 시 재현 방법 출력, 시드 지정 실행 가능)
- pytest와 직접 통합

## 4. 직접 구현하는 항목

| 인증 | 자체 모듈 (표준 라이브러리의 상수 시간 비교 사용) | NFR-SEC-03, 11 |

## 5. 의존성 관리

| 항목 | 결정 | 근거 |
|---|---|---|

## 7. 검토한 대안

| 주제 | 선택하지 않은 대안 | 이유 |
|---|---|---|
| DB 접근 | Flask-SQLAlchemy | 사용자 선택. 테이블 하나에 ORM은 과함 |
| 입력 검증 | pydantic, marshmallow | 사용자 선택. 필드 두 개에 의존성 추가는 과함 |
| 요청 제한 | 자체 구현 | 사용자 선택. 검증된 라이브러리 사용 |
| 서버 | Flask 개발 서버, Gunicorn | 사용자 선택. Waitress는 Windows와 Linux 모두 지원 |
| DB 암호화 | SQLCipher | 요구사항 단계에서 OS 디스크 암호화 전제로 승인됨 |
