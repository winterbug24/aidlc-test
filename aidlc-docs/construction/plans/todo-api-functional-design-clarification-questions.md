## 모호함 1: 미정의 필드 처리 (Q4: "경고창을 통해서 안내")
Q4에 "경고창을 통해서 안내"라고 답하셨습니다. 이 프로젝트는 화면이 없는 REST API(JSON 응답만 반환)이므로 서버가 직접 경고창을 띄울 수는 없습니다.
경고창은 이 API를 호출하는 클라이언트(화면)가 표시해야 하며, API는 그 근거가 되는 정보를 응답에 담아 주는 역할만 할 수 있습니다.
API가 어떤 방식으로 알려 줄지 정해 주세요.

### Clarification Question 1
정의되지 않은 필드가 요청 본문에 포함되어 있을 때 API는 어떻게 응답할까요?

A) 요청은 정상 처리하고, 응답 JSON에 `warnings` 항목을 추가해 무시된 필드 이름을 안내 (HTTP 201/200 유지. 클라이언트가 이 항목을 경고창으로 표시할 수 있음)

B) 요청을 거부하고(HTTP 400), 오류 메시지에 정의되지 않은 필드 이름을 담아 안내 (클라이언트가 오류 메시지를 경고창으로 표시할 수 있음)

C) 요청은 정상 처리하고 응답은 그대로 두되, 서버 로그에만 경고를 기록

D) Other (please describe after [Answer]: tag below)

[Answer]: B
