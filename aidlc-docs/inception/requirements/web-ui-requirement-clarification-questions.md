### Clarification Question 1
8000번 포트를 다른 프로그램이 쓰고 있으면 어떻게 할까요?

A) 자동 변경 - Windows 실행 파일(`.bat`)이 시작할 때 8000번부터 차례로 빈 포트를 찾아(8001, 8002, ...) 그 포트로 서버를 띄우고, 같은 주소로 브라우저를 엶. 실제 사용한 포트를 창에 표시

B) 수동 변경 - 자동으로 바꾸지 않음. 포트가 사용 중이면 "포트가 사용 중입니다. `TODO_PORT`로 다른 포트를 지정하세요"라고 안내하고 종료 (지금 서버의 동작에 안내 문구만 추가)

C) 기본 포트 자체를 덜 겹치는 번호로 바꿈 - `[Answer]:` 뒤에 원하는 포트 번호를 함께 적어 주세요 (예: C : 8765). 사용 중일 때의 동작은 B와 같음
